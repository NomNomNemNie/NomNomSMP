# NomNom SMP — Resource Pack & UI Kit

Bộ resource pack chính thức của **NomNom SMP** (Paper 1.21.11):
custom icons, font tiếng Việt, GUI market/cash/land/casino/mini và class cho tablist/scoreboard.

## Nội dung
- `resourcepack/` — nguồn pack (assets) build bằng script, xuất bản qua **GitHub Releases**
- `docs/design-tokens.md` — bảng màu, kích thước, quy chuẩn panel/nút/icon
- `docs/icons.md` — danh sách glyph icon (font provider `nomnom:ui`)

## Cài đặt (server)
- Pack được phát hành dưới dạng `NomNomUI-vX.Y.Z.zip` (GitHub Releases).
- Server dùng Paper `Player#addResourcePack` để gửi kèm pack weapons (forced) — 1 URL gốc + 1 pack phụ.
